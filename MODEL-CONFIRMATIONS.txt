# Model pages — claims to confirm

Every model page under `/brands/<brand>/<model>-repair` was written from manufacturer manuals, spec sheets and warranty documents. Wherever sources disagreed, a manual table didn't extract cleanly, or a fact needs someone who has been on the job, the claim was **left off the page** and recorded here instead.

Nothing below is published as fact. Confirming an item lets it be added to its page; the source of each is the `toConfirm` list in `content/models/<brand>.ts`.

**Most useful to answer first:**

1. **Which models technicians actually see in DFW.** Pages make no claims about how common a model is locally. Knowing, for example, whether it's 1835 or 1837 panels, or 9100 or 9150 slides, sets which pages get more depth.
2. **Photos.** Only four photos in the library are confirmed to show a specific model: `liftmaster-03` (SL3000) and `liftmaster-22` to `-24` (LA400 job). If any other brand photos or case studies can be matched to a model number, they can go on that model's page.
3. **Parts carried vs ordered.** Pages say common parts (boards, batteries, limit hardware, photo-eyes, remotes) come off the truck and brand-specific parts are ordered. Confirm that matches practice for each brand.
4. **The LA400 → LA500 arm upgrade.** LiftMaster's control box identifies the operator model through a harness on the reset switch, so fitting an LA500 arm to an LA400 box normally means changing that harness. What was changed on that job, and what did the display read afterwards?
5. **Warranty terms.** Each page states the manufacturer's published warranty. Shield's own repair warranty term is still unconfirmed in `content/business.ts`, and the pages render it once it is.

Run `npm run validate:models` for the current list and counts.
